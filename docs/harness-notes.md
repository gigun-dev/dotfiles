# harness 運用のメモ

> `docs/next-directions.md` の棚卸し(2026-09-08)で正典から降ろした。決着済みの経緯。

## 正典の頭が切り詰められていた話 (2026-08-10)

**症状**: `docs/next-directions.md` の頭が 23,191 字まで膨れ、SessionStart の stdout が無言で
切り詰められていた。10,000 字を超えると先頭 2KB のプレビューだけが注入される
(anthropics/claude-code#70460 / #84021)。数セッション分、正典は「注入したつもりで届いていない」状態だった。

**なぜ気づけなかったか**: 当時の `session-start.sh` (v0.2.1) は**頭を全部出してから末尾に警告を
付ける**構造だった。切り詰めが起きた瞬間、末尾にある「切り詰められています」の警告が真っ先に消える。
**切り詰めを知らせる検知器が、切り詰めによって死ぬ。**

**直し方**: v0.7.0 は順序を「(1) 全部計測 → (2) 警告 → (3) 頭」に変えてある。警告は必ず先頭 2KB に
入るので、頭の後半が消えることは避けられなくても、**消えたことが分からない**状態は避けられる。
あわせて予算の単位が行から文字になった(行数は日本語率で 2 倍以上ぶれるため、複数リポジトリへ配る
予算の単位として成立しない)。

**この形の失敗は再発している**: 再起動検証が ssh 到達性しか見ず DNS 全滅を素通りしたのも同じ
(`DF-12`)。「確認した」と書くときは、確認手段自体が生きているかを別経路で疑うこと。

## doctor / tidy の指摘のうち誤検知と裁定したもの (2026-08-11)

**書く理由**: 裁定を残さないと次のセッションが同じ指摘を再発見して再裁定する。それが続くと
「doctor はうるさい」になり、検査そのものが使われなくなる。**却下は理由込みで残して初めて却下**。

- **`✗` pre-push 自己テスト (must-fail) — 誤検知。ただし裏に実バグがあった**
  当時の指摘は「失敗する check コマンドで push が通ってしまう (H-27 型)」。実際には
  `git/hooks/pre-push` は `if ! { ...; }` で正しくグループ化済みで、最小再現でも
  グループ化あり = REJECT / なし = ALLOW と分かれることを確認した。
  **真因はフックの世代**: このリポジトリは v0.3.0 で、自己テストの口
  (`HARNESS_PREPUSH_SELFTEST`) は v0.4.0 で追加されたもの。環境変数が黙って無視され、
  **本物の check コマンド (`nix flake check`) が走って成功した**ため「通ってしまう」と誤報された。
  → v0.4.0 へ移植して解消 (自己テスト両方向 + 本番経路を実測)。配布元 `check.sh` 側の
  バージョンゲート欠落は `~/.harness/inbox/` にメモ済み。
  **教訓**: 指摘文は「グループ化を確認せよ」と誘導する。言われたとおり直しに行くと
  **正しいフックを壊していた**。doctor の指摘は従うものではなく裁定するもの。
- **`⚠️` CLAUDE.md の「毎回/必ず〜する」自動化指示 — 誤検知**
  指摘されたのは「overlay 経由だと**毎回**ソースビルドになる」という行。これは避けたい症状の
  記述であって指示ではなく、Hook 化の対象になりえない。同じ形 (`毎回` `必ず` を含む事実の記述)
  は今後も引っかかるので、**そのつど却下でよい**。
- **`⚠️` 正典の日付が新しいコミットより古い — ほぼ誤検知**
  本文は並行セッションが同日に更新済みで、古いのは H1 見出しの `(YYYY-MM-DD 棚卸し・第2版)` という
  刻印だけだった。棚卸しの版を示す刻印なので、通常の追記では更新しない。

- **`⚠️` tidy の「配布物の世代」(`v0.2.0` / `v0.7.0` が並ぶ) — 誤検知**
  古い版が混ざっているように読めるが、**別々のファイルの版番号を並べているだけ**。
  `v0.2.0` は `.claude/rules/comments.md`、`v0.7.0` は `.claude/hooks/session-start.sh`。
  配布元の `assets/comments-rule.md` も **v0.2.0 が最新**なので、comments.md は最新世代。
  (`git/hooks/pre-push` は今回 v0.4.0 へ更新済み。)
  → **更新すべきものは無い**。この警告は世代が揃うまで出続けるが、揃えようがない
  (ファイルごとに独立した版番号なので)。

**再裁定不要の判定**: 上記 4 つは条件が変わらない限り同じ結論になる。pre-push だけは
フック世代を上げたので**次回から出なくなるはず** — もし出続けたら、それは新しい壊れ方。
